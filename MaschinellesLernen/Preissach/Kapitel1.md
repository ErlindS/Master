# Kategorien von ML Ansätzen & ML Problemstellungen
Machine Learning setzt sich aus:
 - Supervised Learning, 
 - Semi-Supervised Learning, 
 - Reinforcement Learning, 
 - Active Learning und 
 - Unsupervised Learning zusammen.

Im Bereich des Supervised Learnings hat man Regression und Klassifikation
Im Bereich des Unsupervised Learning hat man CLustering, Dimensionalitätsreduktion, Anomalie Detektion und Assoziative Analysis

# Aufgaben des ML/Mustererkennung

Klassifikation:
    Neue Objekte werden einer Klasse zugeordnet

Clustering:
    Aufteilung der Daten in Cluster (Gruppen) ähnlicher Daten, z.B. Dokumenten-Clustering

Regresion:
    Vorhersage einer kontinuerlichen Größe, sehr häufig über die Zeit z.B. Aktienkrus, Temperatur, Energieverbrauch

Anomalieerkennung:
    Identifizieren von Objekten, die sich signifikant von anderen unterscheiden. Beispiel: Kreditkartenbetrug, Predictive Maintanance

Assoziationsanalyse:
    Mustererkennung, die innerhalb der Daten stark abhängige Merkmale entdekct, Warenkorbanalyse für Recommender systems

# Wichtige Eigenschaften von Datenbeständen

- Dimension
- Umfang des Datenbestands
- Merkmalstypen & Skalenniveau
- Bestzung von Datenbeständen
- Datenqualität


# Fluch der Dimensionalitäten
- Der Fluch der Dimensionalitäten beschreibt, dass der Merkmalsraum einer Datenmenge fester Größe zunehmend dünner bestzt ist, wenn die Anzahl der Dimensionen ansteigt
- Das Volumen eines Merkmalsraumes wächst exponentiell in Abhängigkeit der Dimension
