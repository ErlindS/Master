# Ziel
Das Ziel der PCA ist eine Dimensionsreduktion indem mehrere Features kombiniert werden können 

# Vorteile der PCA
- Dimensionsreduktion
- Reduktion von Rauschen in den Daten
- Extraktion unkorrelierter Features die oft zu besseren Modellen führen
- Bessere Visualisierung
- Bessere Erkennung von Mustern

# Nachteile der PCA
- Funktioniert nicht auf unterschiedlich skalierten Daten
- Ist für Daten mit ausreißern nicht gut geeignet
- Die extrahierten Hauptkomponenten können inhaltich nicht gut interpretiert werden
- PCA setzt voraus, dass die Beziehung zwischen den Variablen linear sind
