Die grundlegenden Anforderungen einer Masterarbeit bestehen darin, dass man ein Thema eingeständig aufarbeiten kann. Ebenfalls wird bei einer Masterarbeit eine wissenschaftlichkeit verlangt. Das heißt, dass Veränderungen gemessen werden können und dass Abwägungen zwischen unterschiedlicher Architekturen getroffen werden. 

Also es würde sich anbieten, dass man einen Auftrag nimmt und aus diesem eine Masterarbeit entwickeln könnte. Entsprechend sollte dieser Auftrag wissenschaftlich untersucht werden. Im Sinne, dass man abwägungen aufzeigt und entsprechende Werte misst (Werte messen ist unabdingbar). Bei der Software würde es sich anbieten einen Aspekt der Iso 25010 aufzugreifen (https://iso25000.com/index.php/en/iso-25000-standards/iso-25010) und entsprechend an einer Entwicklung aufzeigt.
